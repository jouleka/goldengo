## GOTCHAS LEARNED THIS SESSION (save you hours)
- **The sim does NOT accept synthetic taps/gestures.** You can't open a `Menu`, push a `NavigationLink`, or
  tap a row in the sim. Verify those interactions on the paired device (tap-test by the user). Screenshots
  of the *closed* state + unit tests + code review cover the rest.
- **`cfprefsd` cache divergence in the sim:** `xcrun simctl spawn booted defaults write group.com.goldengo.app <key> …`
  often does NOT reach the app — the on-disk App-Group plist and the CLI's `cfprefsd` view diverge, so the app
  keeps reading the *old* on-disk value. To force a value the app will read: edit the on-disk plist
  (`PlistBuddy` on `<group container>/Library/Preferences/group.com.goldengo.app.plist`) **then**
  `xcrun simctl spawn booted launchctl stop com.apple.cfprefsd.xpc.daemon` to make the daemon reload. Or just
  read the on-disk plist directly to see what the app actually has. (The app's own read path is correct — this
  is purely a test-tooling quirk.)
- **SourceKit shows stale "Cannot find X / no member" diagnostics** after edits, especially across package
  boundaries — trust `swift build`/`swift test`, not the live diagnostics.
- `XCTAssertEqual(try await actor.method(), …)` fails to compile ("await in an autoclosure") — `await` into a
  local first, then assert.
- App Group container DOES exist in this sim (so `UserDefaults(suiteName: "group.com.goldengo.app")` and the
  rate cache persist there), despite the GoldengoStore comment about the entitlement being stripped.

## WHAT THE MULTI-CURRENCY EPIC ADDED (so you can build on it)
- **FX source = ExchangeRate-API open endpoint** `https://open.er-api.com/v6/latest/USD` (no API key, ~162
  currencies incl. Albanian lek `ALL`, updates daily). Verified live.
- **`CurrencyConverter`** (Core, pure): `convert(amount, from:, to:)` cross-rate via the base; `convert(Money,to:)`;
  `sum([Money], to:)` (skips un-convertible); `isStale(asOf:maxAge:)`. Reads a `RateTable` (base + `[code:Decimal]`
  + `asOf`). Resolution order everywhere: **`ExchangeRateCache().load() ?? SeedRates.table`** (cache → bundled
  real snapshot, offline-safe). `ExchangeRateService.refreshIfNeeded` fetches on launch (wired in `GoldengoApp`
  via `GoldengoStore.refreshExchangeRates()`), 12h gate, never throws to UI.
- **`CurrencyCode`** broadened: `fractionDigits` (ISO 4217 exceptions; **lek is a deliberate 0-digit product
  override** even though ISO says 2 — `MoneyTests` lock this), `symbol` shortlist (else ISO code), `popular`
  shortcut list. `CurrencyCatalog.selectable(from:)` (rate codes minus metals/SDR) + `.filter(_:query:name:)`.
- **Preferred currency** persisted in `SharedSummary` (App Group, key `preferredCurrency`, default `"ALL"`).
  It is the **one unified default currency** (drives Quick Add default + dashboard display) — the user
  explicitly wants ONE currency knob, changeable from Settings OR by tapping the dashboard "This month" total
  (a currency `Menu`). Per-transaction adds override via the Quick Add currency menu (`QuickAddModel.setCurrency`,
  with `CurrencyInput.fit` trimming decimals when switching to a 0-digit currency).
- **`CurrencyPickerView`** (Features, searchable: Suggested + All, Locale names) is **reused** by Settings,
  Quick Add ("More currencies…"), and the dashboard.
- **Dashboard converts:** `IngestionStore.todayTotal(in:rates:)` and `dashboardSummary(in:rates:…)` convert
  every expense to the display currency (no more single-currency filtering); `DashboardSummary.ratesAsOf`
  drives the subtle "Rates as of …" caption. The widget today-total is recomputed in the preferred currency
  (`refreshSharedTodayTotal`). **Recent rows still show each expense in its own currency** — keep that.
- **Subscriptions** already group by merchant+currency (`SubscriptionDetector`) and display per-currency
  (`amountCadenceText`); the Home estimate converts via `dashboardSummary`.
- **No-category expenses → real "Other" category** (`logManual` assigns it; dashboard/recent fall back to
  "Other"); "Other" is also a Quick Add chip.
